SYSTEM ARCHITECTURE

Six Core Capabilities

Engineered to support state and national public-facing digital services.

⚡

Real-Time Event Logging

Authenticated HTTP REST API (POST /api/logs/ingest/) collecting server, runtime, and HTTP telemetry across student portals, tax gateways, and land registry applications.

🏷️

Automated Content Classification

Local, privacy-preserving pattern classifier that categorizes events into 9 functional categories (Security, Auth, Database, System Failure) and 5 severities without external cloud leakage.

🚨

Instant Critical Notifications

Automated anomaly detection triggers immediate in-app incident records and SMTP alerts upon critical failure patterns or authentication bursts (5+ failed logins within 10 minutes).

🔒

Secure Storage & Redaction

Built-in sanitizer strips passwords, session tokens, authorization keys, and Bearer credentials from messages and URLs prior to database persistence, safeguarding citizen privacy.

🔍

Advanced Search & Filtering

Multi-parameter search allows security officers to filter millions of logs by application name, client IP, HTTP status code, severity, date range, and message contents with CSV export.

👥

Role-Based Access Control (RBAC)

Departmental tiers enforce strict permission boundaries between Monitoring Officers (read-only audit/inspection), System Administrators (corrections & resolutions), and Super Admins.

INSTITUTIONAL COMPLIANCE

Compliance with AICTE Guidelines & E-Governance Best Practices

The system fulfills AICTE technical mandates by ensuring continuous operational availability, strict accountability, and data protection:

  • Enhanced System Reliability: Continuous heartbeat tracking and anomaly detection isolate performance degradation before service disruption occurs.
  • Proactive Issue Resolution: Real-time alerts allow technicians to remediate database deadlocks and network timeouts immediately.
  • Institutional Accountability: Immutable audit trails log all user interactions, administrative overrides, and data exports.
  • Data Protection & Local Processing: Complete local classification ensures zero third-party telemetry leakage, protecting student and citizen privacy.
